# Dooray Task Reservation

Dooray 업무·댓글 작업을 **예약**해 두면, 예약 시각에 자동으로 실행해 주는 크롬 익스텐션입니다.
서버 없이 완전히 클라이언트(브라우저)만으로 동작합니다.

## 지원 기능

| 대상 | 작업 |
|------|------|
| 업무(Task) | 생성 · 수정(제목/본문) · 삭제* |
| 댓글(Comment) | 작성 · 수정 · 삭제 |
| 첨부파일 | 업무 생성/수정, 댓글 작성/수정 시 첨부 (이미지는 본문·댓글에 인라인 표시) |
| 멘션 | 멤버 이름 검색 후 본문/댓글에 @멘션 삽입 (서버가 알림 발송) |

모든 작업에 예약 시각을 지정할 수 있으며, 예약 시각이 되면 자동으로 Dooray API를 호출합니다.
sota.dooray.com 실계정으로 인증·업무 생성/수정·댓글 CRUD·첨부 업로드·인라인 이미지·멘션이
전부 실측 검증되었습니다.

\* 업무 삭제는 Dooray 공개 API에서 지원되지 않는 것으로 **실측 확인**되었습니다
(DELETE 요청 시 404). 예약해도 실패할 가능성이 높으며, 웹 UI에서 직접 삭제해야 합니다.

### 첨부파일 동작 방식

- 파일은 예약 등록 시 브라우저 저장소에 보관했다가, 실행 시각에 Dooray 파일 서버
  (`file-api.{cloud}/uploads/...`)로 업로드합니다 (총 25MB 이하).
- Dooray에는 댓글 전용 첨부 API가 없어, 댓글 첨부는 업무(post)에 파일을 올린 뒤
  댓글 본문에서 `![이름](/files/{id})` 형식으로 참조하는 방식(공식 CLI와 동일)을 사용합니다.
- 이미지 확장자(png/jpg/gif/webp 등)는 인라인 이미지로, 그 외 파일은 링크로 삽입됩니다.
- 페이지 에디터([⏰ 예약] 버튼)에서 캡처한 내용은 **화이트리스트 방식으로 정화**됩니다 —
  스마트 에디터의 UI 잔해(이미지 리사이즈 핸들, 편집 버튼 등)를 제거하고, 에디터에
  삽입한 인라인 이미지는 캡처 시 내려받아 실행 시각에 대상 업무의 정식 첨부로
  재업로드한 뒤 본문 참조를 교체합니다 (임시 파일 참조로 인한 깨짐 방지).

### 멘션 동작 방식

- 팝업의 본문/댓글 입력란 아래 **@추가** 버튼으로 멤버 이름을 검색해 멘션을 삽입합니다.
- 삽입 형식: `[@이름](dooray://{orgId}/members/{memberId} "member")` — 서버가 이 마크업을
  인식해 정규화·알림 발송하는 것을 실측 확인했습니다.
- Dooray 페이지 에디터(콘텐츠 스크립트)에서는 에디터 자체의 @멘션 기능으로 작성한
  멘션이 HTML에 포함된 채 그대로 캡처·전송됩니다.

## 설치

1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭 → 이 폴더 선택

## 초기 설정

1. 툴바의 시계 아이콘 클릭 → **설정** 탭
2. **Dooray URL** 입력 (예: `https://sota.dooray.com`)
3. **API Key** 입력
   - 발급 위치: Dooray 웹 접속 → 우측 상단 톱니(설정) → **API** 메뉴 → **개인 인증 토큰** 생성
4. **저장** 후 **연결 테스트**로 인증 확인

민간(`*.dooray.com`) / 공공(`*.gov-dooray.com`) / 금융(`*.dooray.co.kr`) 클라우드는
URL만 넣으면 API 주소가 자동 매핑됩니다. 자체 설치형 Dooray는 입력한 도메인으로
직접 호출하며, 저장 시 해당 도메인 접근 권한을 추가로 요청합니다.

## 사용 방법

### 방법 1 — Dooray 페이지에서 바로 예약 (에디터 통합)

Dooray 페이지의 에디터(댓글 작성, 본문 수정, 업무 생성) 하단 **저장 버튼 옆에
[⏰ 예약] 버튼이 자동으로 추가**됩니다. 스마트 에디터/HTML 에디터에 내용을 작성한 뒤
[⏰ 예약]을 누르면 작성 내용이 그대로 캡처되고, 예약 시각만 골라 등록하면 됩니다.

- 업무 상세 화면에서는 대상 업무가 자동 감지됩니다 (댓글 작성 / 본문 수정)
- 업무 생성 화면에서는 프로젝트와 제목을 선택해 새 업무 생성을 예약합니다

### 방법 2 — 익스텐션 팝업에서 예약

1. **새 예약** 탭에서 작업 유형 선택 (업무 생성/수정/삭제, 댓글 작성/수정/삭제)
2. 프로젝트 → 업무 → 댓글 순으로 대상 선택 (목록에 없으면 "ID 직접 입력…" 선택)
3. 내용과 **예약 시각** 입력 후 **예약 등록**
4. **예약 목록** 탭에서 대기/완료/실패 상태 확인, 재시도·삭제·즉시 실행 가능

실행 결과는 크롬 알림으로도 표시됩니다.

## 동작 원리와 제약

- 예약은 `chrome.storage.local`에 저장되고 `chrome.alarms`로 스케줄링됩니다.
  별도 서버가 없으므로 **예약 시각에 크롬이 실행 중이어야** 전송됩니다.
- 예약 시각에 크롬이 꺼져 있었다면, **다음에 크롬을 켰을 때 밀린 예약을 자동 전송**합니다.
- 업무 수정은 실행 시점에 기존 업무를 먼저 조회한 뒤 담당자·태그·마일스톤 등을
  그대로 유지하면서 제목/본문만 교체합니다 (Dooray의 업무 수정 API가 전체 교체 방식이기 때문).
- API Key는 이 브라우저 프로필의 확장 프로그램 저장소에만 보관되며 외부로 전송되지 않습니다
  (Dooray API 호출에만 사용).

## 파일 구조

```
manifest.json     # MV3 매니페스트
background.js     # 서비스 워커: 예약 스케줄링(chrome.alarms) + Dooray API 호출
content.js        # Dooray 페이지 에디터에 [⏰ 예약] 버튼 삽입 + 예약 모달
popup/            # 예약 등록 · 목록 · 설정 UI
icons/            # 아이콘
```
