# Dooray Task Reservation

Dooray 업무·댓글 작업을 **예약**해 두면, 예약 시각에 자동으로 실행해 주는 크롬 익스텐션입니다.
서버 없이 완전히 클라이언트(브라우저)만으로 동작합니다.

## 지원 기능

| 대상 | 작업 |
|------|------|
| 업무(Task) | 생성 · 수정(제목/본문) · 삭제* |
| 댓글(Comment) | 작성 · 수정 · 삭제 |

모든 작업에 예약 시각을 지정할 수 있으며, 예약 시각이 되면 자동으로 Dooray API를 호출합니다.

\* 업무 삭제는 Dooray 공개 API에 문서화되어 있지 않은 엔드포인트라 환경(테넌트)에 따라
거부될 수 있습니다. 실패하면 알림과 예약 목록에서 사유를 확인할 수 있습니다.

## 설치

1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭 → 이 폴더 선택

## 초기 설정

1. 툴바의 시계 아이콘 클릭 → **설정** 탭
2. **Dooray URL** 입력 (예: `https://sota.dooray.com`)
3. **API Key** 입력
   - 발급 위치: Dooray 웹 접속 → 우측 상단 톱니(설정) → **API** 메뉴 → **개인 인증 토큰** 생성
4. **저장** 후 **연결 테스트**로 인증 확인

민간(`*.dooray.com`) / 공공(`*.gov-dooray.com`) / 금융(`*.dooray.co.kr`) 클라우드는
URL만 넣으면 API 주소가 자동 매핑됩니다. 자체 설치형 Dooray는 입력한 도메인으로
직접 호출하며, 저장 시 해당 도메인 접근 권한을 추가로 요청합니다.

## 사용 방법

1. **새 예약** 탭에서 작업 유형 선택 (업무 생성/수정/삭제, 댓글 작성/수정/삭제)
2. 프로젝트 → 업무 → 댓글 순으로 대상 선택 (목록에 없으면 "ID 직접 입력…" 선택)
3. 내용과 **예약 시각** 입력 후 **예약 등록**
4. **예약 목록** 탭에서 대기/완료/실패 상태 확인, 재시도·삭제·즉시 실행 가능

실행 결과는 크롬 알림으로도 표시됩니다.

## 동작 원리와 제약

- 예약은 `chrome.storage.local`에 저장되고 `chrome.alarms`로 스케줄링됩니다.
  별도 서버가 없으므로 **예약 시각에 크롬이 실행 중이어야** 전송됩니다.
- 예약 시각에 크롬이 꺼져 있었다면, **다음에 크롬을 켰을 때 밀린 예약을 자동 전송**합니다.
- 업무 수정은 실행 시점에 기존 업무를 먼저 조회한 뒤 담당자·태그·마일스톤 등을
  그대로 유지하면서 제목/본문만 교체합니다 (Dooray의 업무 수정 API가 전체 교체 방식이기 때문).
- API Key는 이 브라우저 프로필의 확장 프로그램 저장소에만 보관되며 외부로 전송되지 않습니다
  (Dooray API 호출에만 사용).

## 파일 구조

```
manifest.json     # MV3 매니페스트
background.js     # 서비스 워커: 예약 스케줄링(chrome.alarms) + Dooray API 호출
popup/            # 예약 등록 · 목록 · 설정 UI
icons/            # 아이콘
```
